# GRC & Security Compliance Portfolio

This repository contains professional, automated Governance, Risk, and Compliance (GRC) frameworks, vendor risk management matrices, and compliance tracking tools designed to streamline risk assessments and security audits.

## Included Tools & Frameworks:
* *Enterprise Risk Register:* Structured spreadsheet featuring control tracking, risk scoring logic, and severity calculations.
* *Third-Party & Fourth-Party Vendor Risk Assessment:* Automated vendor evaluation tracking matrices for managing supply chain security.
* *HIPAA Risk Assessment:* Compliance mapping tool tailored for healthcare data protection standards.

## Core Capabilities:
* Risk identification, evaluation, and scoring methodologies.
* Third-party vendor risk lifecycle tracking.
* Security framework alignment (NIST CSF, HIPAA, ISO 27001).
